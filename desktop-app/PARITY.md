# Возможности настольного VortexChat

Ориентир: [Chatterino+](https://chat.eblo.id/#changelog). VortexChat является отдельной реализацией и не использует его закрытые сервисы.

## Работает

- Несколько каналов в отдельных панелях, сохранение каналов и настроек.
- Чтение Twitch IRC с переподключением и статусом соединения.
- Вход Twitch по коду устройства и отправка через официальный Twitch API после подтверждения.
- Смайлы Twitch, 7TV, BTTV и FFZ; автодополнение при наборе кода.
- Поиск в текущих сообщениях, пауза прокрутки, подсветка слов, копирование, кликабельные упоминания и локальная история зрителя.
- Три палитры, размер текста, компактный режим, время сообщений, окно поверх других окон.
- Локальный OBS-оверлей и два формата Windows `.exe`.

## Пока отсутствует

- Теневой чат, общие баны, PLUS-пейнты и донаты в чате: для них требуются собственный сервер и источники данных.
- Полноценные инструменты модерации, баллы канала, закрепы и журнал модерации.
- Архив истории между запусками, синхронизация настроек между устройствами и Linux-сборка.

Чтение чата доступно без входа. Для отправки сообщений нужен Client ID собственного приложения Twitch. Не публикуйте Client Secret и ключ доступа.
