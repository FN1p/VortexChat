# VortexChat для Windows

Настольное приложение показывает чаты Twitch без входа в аккаунт, загружает часть смайлов 7TV и BTTV и поднимает локальный оверлей для OBS на `http://127.0.0.1:5222/overlay`.

Отправка сообщений пока недоступна: анонимное подключение IRC не даёт права писать в Twitch. Поле ввода отключено, чтобы приложение не показывало неподтверждённую отправку.

## Сборка

На Windows с Node.js: `npm ci`, затем `npm run dist` из этой папки. Результат находится в `dist/`:

- `VortexChat-Setup.exe` — установщик с ярлыками.
- `VortexChat-Portable.exe` — переносимый запуск без установки.

Оба файла x64. Они не подписаны цифровым сертификатом. Если порт 5222 занят, приложение продолжит работать без OBS-оверлея и покажет ошибку.
