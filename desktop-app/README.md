# VortexChat для Windows

Настольное приложение показывает чаты Twitch, загружает смайлы Twitch, 7TV, BetterTTV и FrankerFaceZ и поднимает локальный оверлей для OBS на `http://127.0.0.1:5222/overlay`. Есть автодополнение смайлов, поиск, пауза прокрутки, подсветка слов, локальная история зрителя, три палитры и сохранение каналов и настроек.

Для отправки сообщений нужен вход в Twitch. Зарегистрируйте своё приложение в [Twitch Developer Console](https://dev.twitch.tv/console), выберите публичный тип клиента и введите его Client ID в окне «Войти». Программа откроет Twitch для подтверждения по коду устройства. Client Secret не нужен. Токены хранятся в профиле Windows в зашифрованном виде, когда доступна защита Electron `safeStorage`; при отсутствии защиты они сохраняются только на время работы программы. Отправка считается успешной только после подтверждения Twitch API.

Остальные возможности и ограничения перечислены в [PARITY.md](PARITY.md).

## Сборка

На Windows с Node.js: `npm ci`, затем `npm run dist` из этой папки. Результат находится в `dist/`:

- `VortexChat-Setup-1.3.0.exe` — установщик с ярлыками.
- `VortexChat-Portable-1.3.0.exe` — переносимый запуск без установки.

Оба файла x64. Они не подписаны цифровым сертификатом. Если порт 5222 занят, приложение продолжит работать без OBS-оверлея и покажет ошибку.
