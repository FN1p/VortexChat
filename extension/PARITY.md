# Сопоставление с Chatterino+ для браузера

Источник: [журнал обновлений Chatterino+](https://chat.eblo.id/#changelog), вкладка «Расширение Chrome · Firefox», просмотрен 24 октября 2026 года. В журнале также есть функции настольного клиента; они не входят в текущую область VortexChat.

## Реализовано в VortexChat 4.1.0

- Смайлы 7TV, BTTV и FFZ, избранное, меню Twitch, автодополнение и наложение Zero-Width.
- Пейнты и бейджи 7TV для пользователей, найденных через публичный профиль 7TV.
- Пауза чтения, локальная история пользователя, копирование текста, упоминание правым щелчком, подсветка слов, группировка повторов.
- Скорость чата, размер текста, отступы, показ времени, настройки кнопки копирования.
- Перенос настроек JSON и восстановление данных API из локального кэша при временных сбоях.
- Ambilight при доступном чтении кадров видео и просмотр клипов поверх страницы через официальный Twitch embed.

## Ещё нет в браузерном расширении

- Общие баны и досье, PLUS пейнты и бейджи, зеркало недоступных API. Они зависят от серверной части Chatterino+; её нельзя использовать как публичный API стороннего клиента. Собственный аналог потребует отдельного сервера и источника данных.
- Ползунок модерации, действия с задержанными сообщениями AutoMod, история модерации и полные карточки зрителей. Сейчас доступна встроенная карточка Twitch и история сообщений, замеченных текущей вкладкой.
- Опросы и прогнозы под чатом, расширенное меню GIF и открепляемое окно смайлов.
- Догон эфира, полная реализация клипов (качество, громкость, метаданные и повтор чата), настройки плеера и левой панели Twitch.
- Интеграция с eblo.id для просмотра и загрузки медиа, уведомления об упоминаниях со звуком, настройки блокировки пользователей.

Реальная совместимость с авторизованным Twitch и другими чат-расширениями ещё не проверена. Изменения Twitch могут потребовать обновления DOM-селекторов.
