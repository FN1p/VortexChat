# VortexChat — расширение для Twitch

VortexChat улучшает встроенный чат Twitch в браузере. Текущий приоритет — удобство чтения и стабильность. Это самостоятельный проект PFT Studio, вдохновлённый возможностями чат-клиентов; он не является официальным расширением 7TV или полной копией Chatterino+.

## Что доступно в 4.0.0

- Кнопка быстрых настроек в шапке чата открывает параметры оформления и чтения без перехода в основное окно настроек.
- Три палитры Twitch и два варианта плотности чата доступны также в окне расширения. Меню смайлов показывает недавно использованные 7TV, BTTV и FFZ.

- Код 7TV вставляется в состояние редактора Twitch, чтобы Enter и кнопка отправки распознавали сообщение, а не только видимый текст в поле.

- Перед вставкой кода смайла расширение проверяет, что курсор находится внутри редактируемого поля чата. Текст больше не вставляется в случайное место страницы при сбое выбора редактора.

- Один клик по смайлу делает одну вставку кода в поле чата. Подсказка при наборе доступного кода видна поверх меню смайлов и обновляется даже при нестандартных событиях редактора Twitch.

- Быстрые повторные запросы одного смайла больше не отправляют сообщение несколько раз. При наборе кода загруженного смайла появляется подсказка с картинкой и провайдером; Tab выбирает его.

- Новая тема VortexChat для навигации Twitch, чата, ввода, меню смайлов и окон расширения. Выключается в разделе «Интерфейс» или во всплывающем окне.

- Ambilight стал шире и ярче. Размах и яркость можно менять в окне расширения и настройках Twitch. У расширения новый логотип VortexChat.

- Ambilight рисуется отдельным слоем поверх видео и не меняет разметку плеера Twitch. Чат больше не затемняется; подсветка учитывает чёрные полосы видео.

- Если все API провайдеров дают ошибку через фоновый скрипт, расширение пробует прямые запросы и показывает техническую причину в окне статуса.

- Загрузка сета 7TV для `stintik` и других каналов стала устойчивее к отсутствию комнаты FFZ и медленному ответу API. Ошибки источников видны в статусе, загрузка повторяется автоматически.
- Нативные упоминания Twitch открывают карточку пользователя; кнопка копирования использует область кнопок Twitch и не увеличивает расстояние между сообщениями.

- Кнопка копирования находится рядом с ником и не растягивает строки чата. Упоминания `@nickname` в сообщениях открывают карточку пользователя.

- Ambilight с кнопкой ✦ в плеере и настройками яркости, отклика, затемнения. Если кадры видео защищены браузером, цветная подсветка не появится.
- Обычный клик по ссылке Twitch Clip открывает клип поверх страницы. Плеер Twitch встроен в окно; звук основного видео временно выключается. Ctrl, Shift и средняя кнопка открывают ссылку обычным способом.
- Официальный встроенный плеер клипа не даёт задавать качество и громкость программно. Сведения об авторе, просмотрах, переход в VOD с точного момента и повтор чата требуют авторизованного API и пока отсутствуют.

- Смайлы 7TV берут адрес картинки из метаданных API. Рендер чата обрабатывает вложенный текст и сообщения без привычных текстовых классов Twitch.

- API 7TV, BTTV и FFZ загружаются через фоновый скрипт расширения. При сбое основного адреса 7TV проверяется второй официальный адрес. Ответы API из удачных загрузок хранятся локально до 14 дней; если сеть временно недоступна, расширение использует их и показывает это в статусе. Кэш содержит данные смайлов, но их картинки по-прежнему загружаются с CDN провайдеров.
- Скорость новых сообщений за последние 10 секунд в шапке чата. В настройках можно менять отступы между строками и смайлами, а также скрывать кнопку копирования.
- Правый щелчок по нику вставляет @упоминание, по смайлу в чате — его код в поле ввода Twitch.

- Настоящая пауза чтения: кнопка Ⅱ в шапке чата и опциональная пауза при наведении. На паузе видимая лента фиксируется, новые сообщения считаются отдельно. «К эфиру ↓» возвращает к живому чату. Снимок сохраняется, даже если Twitch удаляет старые строки из своей ленты.
- История пользователя по кнопке ≡ рядом с ником: поиск, копирование, упоминание, профиль и переход к встроенной карточке Twitch. Нативная карточка доступна, пока пользователь присутствует в текущей ленте.
- Кнопка ⧉ копирует исходный текст сообщения вместе с кодами смайлов.
- Избранные смайлы: правый клик по смайлу в меню Twitch или ★ в его карточке. Отдельная секция «Избранное» поддерживает поиск. Показываются только доступные на текущем канале смайлы включённых провайдеров; остальные сохраняются для других каналов.
- Экспорт и импорт настроек вместе с избранным через JSON-файл в окне расширения. Импорт заменяет текущие настройки. История сообщений в файл не включается.
- Размер текста от 11 до 24 px, чередование фона строк.
- Время появления сообщения в расширении. Уже отображаемые метки Twitch не дублируются. Для старых сообщений это время первого обнаружения, а не отправки.
- Подсветка сообщений по словам и фразам через запятую, без учёта регистра. Можно указать свой ник. Совпадение ищется как подстрока, без регулярных выражений.
- Группировка одинаковых сообщений одного автора, идущих подряд, со счётчиком повторов. Можно отключить, чтобы снова увидеть все строки.
- Канальные и глобальные смайлы 7TV, BetterTTV и FrankerFaceZ; отдельные переключатели провайдеров.
- Смайлы в меню Twitch, поиск, превью, карточки и наложение Zero-Width 7TV.
- Автодополнение по Tab: стрелки вверх/вниз выбирают вариант, Escape закрывает подсказки. Enter сохраняет обычное поведение Twitch. При редактировании середины сообщения расширение не заменяет текст автодополнением.
- Обновления сета через 7TV EventAPI с переподключением после разрыва.
- Реальное состояние вкладки, загрузки смайлов и соединения в окне расширения.
- Настройки сохраняются локально и применяются к открытым вкладкам Twitch без перезагрузки страницы.

При совпадении кодов канальные смайлы имеют приоритет над глобальными; внутри одной категории порядок — 7TV, BTTV, FFZ. Отключение провайдера возвращает доступный смайл другого провайдера или исходный текст.

## Установка или обновление

1. Распакуйте архив расширения либо используйте эту папку `extension`.
2. Откройте `chrome://extensions/` в Chrome, `edge://extensions/` в Edge или страницу расширений своего Chromium-браузера.
3. Включите режим разработчика и нажмите «Загрузить распакованное расширение».
4. Выберите папку, в которой находится `manifest.json`.
5. При обновлении нажмите кнопку перезагрузки на карточке VortexChat.
6. Обновите вкладку Twitch. Настройки открываются через значок расширения или кнопку в заголовке чата.

Для запуска расширения не нужны npm, Electron или настольный клиент.

## Ограничения

- Paints и Badges 7TV пока не реализованы. Случайная имитация красок из предыдущей версии удалена.
- История собирается только во время работы этой вкладки, хранится в памяти и исчезает при перезагрузке. Лимит — 1200 сообщений на канал, до 5 каналов; в карточке показываются последние 100 совпадений. Это не полная серверная история Twitch.
- Пауза фиксирует отдельный снимок для чтения. Новые сообщения продолжают поступать в Twitch; при возвращении к эфиру его собственный лимит истории уже мог удалить часть старых сообщений.
- Общие баны, самостоятельные модераторские API, личные смайлы, дополнительные эффекты и интеграция с плеером пока не реализованы. Доступные нативные действия Twitch открываются через его карточку.
- Расширение зависит от DOM Twitch и доступности API провайдеров. После изменений сайта селекторы и мост ввода могут потребовать обновления.
- Если Twitch или CDN картинок блокируются провайдером связи, браузерное расширение не может восстановить к ним доступ само. Локальный кэш помогает только после успешной прежней загрузки данных, а для изображений нужен доступ к CDN.
- Функции Chatterino+ с их сервером (общие баны, PLUS пейнты и бейджи, зеркало API, теневой чат) не подключены к VortexChat. Для собственных аналогов нужен отдельный сервер и его поддержка. Остальные расхождения перечислены в `PARITY.md`.
- Локальные тесты проверяют обработку DOM и сетевые сценарии на фикстурах. Авторизованный чат Twitch, модераторский интерфейс и совместная работа с другими чат-расширениями требуют отдельной ручной проверки.

## Проверка разработки

Из корня репозитория, Node.js 20+:

```sh
node --test tests/extension.test.cjs
node tests/browser-server.cjs
```

Локальные страницы:

- `http://127.0.0.1:5187/forsen` — регрессионные проверки чата.
- `http://127.0.0.1:5187/popup-tests` — проверки быстрого изменения и импорта настроек.
- `http://127.0.0.1:5187/forsen?preview=1` — интерактивное превью паузы и истории.
- `http://127.0.0.1:5187/popup-preview` — окно расширения.
 Стенд использует подставные API и не отправляет сообщения в Twitch. Статус подключения и количество смайлов в превью демонстрационные.

## Файлы

- `manifest.json` — Manifest V3 и порядок загрузки.
- `core.js` — настройки, маршруты, каталог смайлов, формат резервной копии и ограниченное хранилище истории.
- `background.js` — запросы к публичным API и ограниченный локальный кэш.
- `chat-tools.js` — пауза чтения, карточка пользователя, история, копирование и управление диалогами с клавиатуры.
- `content.js`, `content.css` — обработка чата, пикер, настройки и EventAPI.
- `page-bridge.js` — мост ввода Twitch в MAIN world с подтверждением обработки.
- `popup.html`, `popup.css`, `popup.js` — окно расширения.
