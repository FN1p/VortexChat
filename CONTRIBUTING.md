# Руководство по разработке (Contributing to VortexChat)

Спасибо за интерес к развитию проекта **VortexChat** от студии **PFT Studio**!

## 🛠️ Разработка и стандарты

1. **Десктопный клиент (`desktop-app/`)**:
   - Используйте чистый JavaScript/Node.js и Electron.
   - Избегайте добавления тяжелых C++/Rust нативных модулей, требующих компилятора Visual Studio, для обеспечения 100% надёжности сборки на любой машине.
   - Все изменения оверлея должны сохранять совместимость с встроенным сервером на порту `5222`.

2. **Расширение для Chrome (`extension/`)**:
   - Строгое соблюдение спецификации **Manifest V3**.
   - Не используйте небезопасные `eval` или динамические внешние скрипты.

## 🚀 Процесс внесения изменений

1. Сделайте Fork репозитория.
2. Создайте ветку для вашей фичи: `git checkout -b feature/awesome-feature`.
3. Зафиксируйте изменения: `git commit -m 'feat: add awesome feature'`.
4. Отправьте ветку: `git push origin feature/awesome-feature`.
5. Откройте Pull Request с подробным описанием изменений.
